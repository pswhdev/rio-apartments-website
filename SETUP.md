# Rio Stays — Tropical & Modern website (v1)

A lightweight static brochure website for two Rio de Janeiro holiday apartments. English and Brazilian Portuguese; all bookings are completed via Airbnb.

## Preview
Open `index.html` in a browser, or run VS Code Live Server. No build step or dependency install.

## Airbnb listing links
Configured in `index.html`:
- Apartment 01: https://www.airbnb.com/h/beach-and-mountains-rio
- Apartment 02: https://www.airbnb.com/h/pepe-mar-e-montnhas

These are the exact custom listing slugs provided by the owner; their spelling is deliberately preserved. Verify each destination opens the correct public listing before publication.

## Publishing checklist
- Replace both apartment images (currently generic illustrative Unsplash pictures) with real, licensed property photos.
- Replace generic property descriptions with verified specifics, amenities and neighborhoods, in both translations (see `script.js`).
- Replace generic coastal hero and Rio section imagery with authentic licensed Rio photographs.
- Confirm the working brand name **Rio Stays**, choose domain and update SEO/metadata.
- Add proper localized URLs with canonical/hreflang/sitemap for stronger bilingual SEO; current switch is client-side only.
- Test all Airbnb booking links, responsive layout, accessibility and image licensing.
- Deploy using a static host (GitHub Pages, Cloudflare Pages, Netlify, etc.). No deployment is configured yet.

No guest data collection, payments or direct booking functionality is implemented. Keep the site focused on discovery and Airbnb conversions.
